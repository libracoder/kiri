Code ported into Kiri
=====================

Parts of Kiri's image builder are translations into Rust of other projects'
code, made so that a build gives the same result, byte for byte, as the
reference builder. Each such file says at its top which upstream files it
came from; where only one function of a file was translated (Ulimit::parse
in kiri-forge/src/ports/mod.rs, the function same in
crates/kiri-init/src/linux/stepdiff.rs), the notice is on that function
instead. They are changed versions of that code, not the originals.

The image builder, Forge (Kiri's own build engine), is a library of its
own, kiri-forge (https://github.com/libracoder/kiri-forge, Apache-2.0),
which Kiri compiles in; paths below that start with kiri-forge/ are files
of that repository, whose NOTICE carries the same credits.

This section is kept by hand in docs/licensing/notices/ and added to NOTICE
by scripts/ci/notices.sh.

BuildKit — Apache License 2.0
----------------------------------------------------------------------
Source: https://github.com/moby/buildkit (v0.33.1)
Copyright The BuildKit Authors. BuildKit ships no NOTICE file. The text of
the Apache License 2.0 is given above, under "Rust workspace and locked
dependencies".

Translated from it:
- kiri-forge/src/dockerfile/ (parser.rs, directives.rs,
  instructions.rs, shell.rs, linter.rs, suggest.rs): frontend/dockerfile
  parser, instructions, shell and linter packages, util/suggest
- kiri-forge/src/convert/ (mod.rs, dispatch.rs, expose.rs, git.rs,
  util.rs): frontend/dockerfile/dockerfile2llb, frontend/dockerfile/dfgitutil,
  util/system/path.go, util/gitutil/git_url.go, util/sshutil/scpurl.go
- kiri-forge/src/copy/ (checksum.rs, fsutil.rs, unpack.rs, user.rs):
  cache/contenthash, solver/llbsolver/file, solver/llbsolver/ops/user_linux.go
- kiri-forge/src/build/progress.rs (source_snippet):
  solver/errdefs/source.go
- crates/kiri-init/src/linux/stepdiff.rs, the function same: the order of
  decisions of sameDirent in util/overlay/overlay_linux.go
Followed for behaviour, written independently: the rest of
crates/kiri-init/src/linux/stepdiff.rs (util/overlay/overlay_linux.go),
crates/kiri/src/daemon/buildfetch.rs (source/http/source.go).

Formats and protocols implemented from their specifications
----------------------------------------------------------------------
No code was taken for these; they are named so that nobody has to wonder.
- The ssh-agent protocol and private key file formats
  (crates/kiri/src/sshfwd.rs), from draft-miller-ssh-agent, OpenSSH's
  PROTOCOL.key document and RFC 5915; signing is done by the ring crate. It
  is tested against OpenSSH's own programs and contains no OpenSSH code. Its
  key-parsing error texts are those of Go's x/crypto/ssh, which buildx
  prints for the same key files.
- Error and warning texts match the reference builder's word for word
  wherever a build prints them, so that scripts reading them keep working.
