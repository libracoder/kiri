
## New
- **Kiri for Windows**: an installer for x64 PCs and one for ARM PCs (Surface, Snapdragon laptops). The download page picks the right one, or you can choose. The installers aren't signed yet, so Windows asks you to confirm before it runs.
- **Every download names its chip**: Mac, Windows and Linux files say arm64 or x86_64, and each copy of Kiri updates from its own feed.

## Better
- **Linux packages** are tested on Ubuntu and Fedora before each release: install, service, a container with internet, a published port, then a clean uninstall.
- **The .rpm packages** are about a quarter smaller.
- **The download page** shows only what's actually available, so every link works.
