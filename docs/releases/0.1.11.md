## New
- **IPv6 networks**: `docker network create --ipv6` (and `--ip6`, Compose `enable_ipv6`) works, including IPv6-only networks (`--ipv6 --ipv4=false`), NAT66 to the internet and ports on `[::1]`. Kiri now passes the same IPv6 checks as Docker on Mac, Windows and Linux.
- **Docker's DNS at 127.0.0.11**: containers on your own networks find each other by name the way they do under Docker, and one slow `--dns` server no longer holds up every other lookup.
- **Share names are checked before they're yours**: `kiri share reserve NAME` asks for the name, and `kiri share names` shows the ones waiting and any that weren't approved, with the reason.

## Fixed
- **kind and `kiri k8s` reach your computer**: `host.docker.internal`, `host.kiri.internal` and `gateway.docker.internal` resolve inside kind nodes, their pods and `kiri k8s` pods.
- **A volume over an image folder keeps its owner**: it used to come up owned by root with no permissions, so redis couldn't save.
- **Networks that should be cut off are**: IPv4-only networks no longer hand out IPv6, `--internal` networks fail straight away instead of hanging, and the `disable_ipv6` sysctl is honoured.
- **`docker ps --filter name=^web$`** matches exactly, as Docker does.
- **Builds no longer stall** on the image mirror on Windows and Linux, including after upgrading and when the network moves, and `FROM` an image that exists only in Kiri works there.
- **`--add-host name:host-gateway` in a classic build (`DOCKER_BUILDKIT=0`) on Windows and Linux** points at your computer (the bridge gateway), as `docker run` does, instead of an address that only exists on a Mac.
- **`docker inspect` of a container sharing another's network** (`--network container:…`) shows no networks of its own, as Docker does, instead of a made-up one.
- **Windows**: networks work on WSL2's own kernel, which lacks a firewall module Kiri used for IPv6.

## Better
- **Builds start faster after a pause**: an idle build worker is paused instead of stopped, so the next build starts in about a second with its cache warm. It still stops before the engine sleeps, so an idle Kiri uses no more memory than before.
- **Containers list**: every column sorts and resizes, as in Images.

## Known issue
- **`--add-host name:host-gateway` with BuildKit** still fails, with buildx's own error, because buildx only allows it for Docker's built-in builder. Use the gateway address itself, or `DOCKER_BUILDKIT=0`. Kiri's own built-in builder is planned for a later release.
