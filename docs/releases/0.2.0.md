## New
- **USB devices in containers (beta).** Hand a serial adapter, a Zigbee stick or another device to your containers, on Mac, Windows and Linux. Its details show where it is inside Linux, with the `--device` line to copy.
- **Kiri in 15 languages.** It asks the first time it opens; change it in Settings › Appearance.
- **Container names answer on the ports you choose,** in Settings › Domains, and a container that publishes port 80 or 443 gets it.

## Fixed and improved
- **Mac: the VM no longer stops under heavy network traffic,** and keeps the Mac's time after it sleeps.
- **amd64 builds on Apple silicon run through Rosetta,** so `bun install` no longer crashes.
- **`docker system df` shows real sizes,** and `docker load` takes images saved by Podman.
- **DDEV and Typesense start,** and php-fpm and nginx running as a user can open their logs.
- **Mac: the Finder mount never covers your files at `~/Kiri`,** and the Dock icon hides with the window.
- **Linux: the window no longer flickers,** and Kiri installs beside Docker's own Compose and buildx.
- **Windows: setup carries on after a failed step** and says why an image pull failed.
