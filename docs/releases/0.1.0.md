## New
- **Kiri Share**: press Share on a container and it answers at a public HTTPS address on runkiri.cloud. Shares from all your computers show in one list.
- **Kubernetes in the window**: Pods, Services and Settings → Kubernetes. kind runs on Kiri too.
- **Builds**: a Builds view, a page for each image with its layers, and a vulnerability scan.
- **Images**: search Docker Hub, watch each layer pull, and cancel a pull. Sign in to private registries.
- **Restart** is the first button on a running container.
- **Updates in the window**: they download in the background, install on restart, and open this page.
- A theme button beside the name, a text size in the View menu, and sortable, resizable columns.

## Better
- Pulls don't hang: a dead registry address is skipped, a stalled download picks up where it stopped.
- More of the Docker API: networks, `--network container:`, health checks, sysctls, log files and volumes.
- Containers aren't reachable from your network unless you publish a port.
- Container status counts as it goes, says Stopped for a clean stop, and shows failures in red.
- The VM sleeps when idle, even with the window open, and gives memory back.
- Settings opens straight away, and the window stays responsive while you drag and resize.

## Fixed
- Security fixes in the engine: layers, file sharing, DNS forwarding and network relays.
- Kiri recovers by itself after a stale daemon socket.
