
## New
- **`kiri` in every terminal**: zsh and bash, in Terminal, iTerm, VS Code, tmux and IDE terminals, not only new Terminal windows.
- **Share traffic**: a share shows its traffic and how long it has been up. Another computer's share can be stopped from here too.

## Better
- **Containers** look the same on every row: the address or image on a second line, columns as wide as their values, and a Compose project's containers grouped under it.
- **Container details** start with the name and state, then the image, a short ID you can copy, and the Compose project.
- **Shares** are faster over long distances, using several connections at once.

## Fixed
- With saved column widths, a row's last button no longer runs past the Actions column.
