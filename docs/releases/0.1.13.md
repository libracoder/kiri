## New
- **Check for updates from Settings → About.** The version line says what Kiri last found ("up to date, checked 3 min ago") and has **Check now**. When there's a newer version it shows Download, What's new and the notes, then a progress bar, then **Restart to update**. Until now Kiri only looked when it opened, and checking by hand was hidden in the Mac menu bar or the Windows tray icon.
- **Check for updates automatically**, a switch next to it, on by default. Turned off, Kiri only looks when you press Check now.

## Fixed
- **Windows: What's new shows the release notes.** The update card on Windows never had What's new, because the Windows update feed carried no notes. Every release now ships its notes on Mac and Windows alike.
- **Linux: the window no longer offers the Mac app as an update.** It read the Mac's update feed. It now tells you when a newer version is out and links to the releases page for the new `.deb` or `.rpm`; `kiri update` on Linux does the same.
