## New
- **Kiribra:** the project is renamed from Kiri. App name, `kiribra` Docker/kubectl context, `~/.kiribra` state, and `*.kiribra.local` domains.
- **Settings → Web UI:** start and stop `kiri ui --web` from the window, pick port and LAN access, open the URL in a browser, and bring it back on launch when left on.
