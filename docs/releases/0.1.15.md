## New
- **Linux: signed packages and repositories.** Every `.rpm` and the Linux checksums are signed with the Kiri Releases key, and download.runkiri.com now serves signed apt and dnf repositories, so `apt upgrade` and `dnf upgrade` can keep Kiri current. The key is `kiri-archive-key.asc` on the download site.

## Fixed
- **Mac: image files no longer come back empty.** When the engine went to sleep or stopped right after a pull, the VM could stop before its disk had caught up, and a newly unpacked image could keep its file names but lose their contents. Builds then failed in `RUN` steps and some programs (iperf3, for one) wouldn't start. Kiri now waits for the engine's VM to power off, writes each layer out in full before using it, and unpacks again any layer that was cut short.
- **`kiri share` no longer crashes when its output goes away.** Piping it into a command that exits, or closing the terminal it printed to, made it panic and leave a crash report. Kiri commands now end quietly when their output is closed.
